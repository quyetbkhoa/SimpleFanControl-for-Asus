SIMPLEFANCONTROL FOR ASUS
ENGLISH / TIENG VIET

START / KHOI DONG
1. Exit the old version from system tray.
   Thoat hoan toan ban cu trong system tray.
2. Open SimpleFanControlForAsus.exe.
   Mo SimpleFanControlForAsus.exe.
3. Accept the Windows UAC prompt.
   Chap nhan cua so UAC cua Windows.

FAN CONTROL / DIEU KHIEN QUAT
- Fan control: enable or disable application control.
  Fan control: bat hoac tat quyen dieu khien cua ung dung.
- Fan curve off: use the manual slider.
  Tat Fan curve: dieu khien bang thanh truot.
- Fan curve on: speed follows the temperature graph.
  Bat Fan curve: toc do chay theo bieu do nhiet do.
- Blue points edit the curve; orange line is current CPU temperature.
  Diem xanh de chinh bieu do; vach cam la nhiet do CPU hien tai.
- Reset default: 30C/40%, 55C/50%, 70C/65%, 80C/90%, 90C/100%.

SETTINGS / CAI DAT
- Start with Windows: launch automatically after sign-in.
  Tu khoi dong sau khi dang nhap Windows.
- Polling interval: 1, 2, 3, 5 or 10 seconds.
  Chu ky cap nhat: 1, 2, 3, 5 hoac 10 giay.
- Default polling: 2 seconds / Mac dinh: 2 giay.
- Closing minimizes to tray by default.
  Bam X se thu nho xuong system tray theo mac dinh.
- Exit from Settings or the tray menu.
  Thoat that trong Settings hoac menu system tray.
